# S7 AI Studio 1.1.0

## Windows 7 兼容包

- Windows 7 SP1 x64 请选择 `S7AIStudio-1.1.0-Windows7-x64.zip`，解压后运行 `S7AIStudio.exe`。
- 需要 Universal CRT（KB2999226）、安全 DLL 加载支持（KB2533623 或包含该修复的系统更新），以及支持 OpenGL 2.1 的显卡驱动。
- 兼容版可在“更新”页检查版本，请手动下载新的 Windows 7 兼容包进行升级。
- Windows 7 实机启动和现场 PLC 连接待验证。

## 常规 Windows 包

- Windows 10 / 11 x64 请选择 `S7AIStudio-1.1.0-Windows-x64.zip`。现有常规版用户也可在“更新”页升级。
- 修复部分构建中程序内中文帮助出现乱码的问题。
