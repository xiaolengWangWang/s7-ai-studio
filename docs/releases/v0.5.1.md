# S7 AI Studio 0.5.1

Windows x64 GUI 预览版。

## 更新

- 导入 CSV/XLSX 点表后，点击“读取一次”按点表顺序逐个地址读取，每个地址完成后显示读数、质量和核对结果。
- 显示逐点读取进度，保留每个属性的名称、单位和期望值核对。
- 单个地址被设备拒绝时继续下一项；连接失效或操作取消时停止，保留已完成结果，未执行地址标记“未读取”。
- 修复已经停止的旧轮询覆盖点表验证结果及进度的问题。
- 没有期望值的失败点也显示“读取失败”，避免被当作“未核对”。
- 命令行 `verify` 同样按地址逐项读取；普通手动读取和连续轮询保留批量方式。

## 使用

解压 Windows x64 ZIP 后运行 `S7AIStudio.exe`，无需安装 Go 或 MinGW。导入点表后点击“读取一次”启动逐点验证；需要中止时点击“断开”。程序内“帮助”页提供连接与点表格式说明。

## 使用范围

提供经典 S7 TCP（ISO-on-TCP）通信。型号档案用于配置连接参数，具体 CPU、固件和接入路径仍需现场验证。PPI、MPI、PROFIBUS、OPC UA、S5 专用协议、Telegraf `DT` 类型和计数器/定时器区域不在本版范围内。本次验证使用合成对端与固定协议报文，不代表已完成全部型号的实机认证。
