# S7 AI Studio 1.0.0

## 更新内容

- 连接成功后，在窗口顶部显示本次使用的 TSAP 及其可解析的路由机架号、槽号。
- 新增“查询设备连接数”，可按需读取 PLC 的当前连接资源和最大通信连接数。设备未提供的数据会显示为不可用。
- “报文”页支持按连接和读取筛选，可查看 COTP 握手、S7 PDU 协商、原始收发字节，以及读取测点的返回值、质量、错误和耗时。连接报文独立保留，便于在轮询期间回查握手。
- “日志”页记录连接目标、协商过程和连接资源查询结果。

## 安装与升级

下载 Windows x64 绿色包，解压后运行 `S7AIStudio.exe`。现有 `0.6.0` 用户也可在“更新”页检查并安装本版。
