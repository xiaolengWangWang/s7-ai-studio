# S7 AI Studio 1.0.1

## 界面

- 调整连接和写入区布局，给点位表留出更多空间。
- 连接出错时可直接打开日志，报文页新增“异常”筛选。

## 日志

- 日志支持按级别和分类筛选，按消息、目标地址和请求 ID 搜索。可复制详情或筛选结果，也可导出 UTF-8 文本。
- 带关联报文的日志可打开对应响应。轮询的重复异常合并记录，异常变化和恢复各有记录。
- 界面保留最近 300 条日志，关键会话事件归档到 SQLite。

## 安装与升级

下载 Windows x64 绿色包，解压后运行 `S7AIStudio.exe`。现有用户也可在“更新”页检查并安装本版。
