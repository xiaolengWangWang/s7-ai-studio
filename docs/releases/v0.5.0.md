# S7 AI Studio 0.5.0

Windows x64 GUI 预览版。

## 更新

- 扩展 viSCADA / Telegraf S7 点表地址：`C`（CHAR）、`LI`（LINT）、`LR`（LREAL）、`S<偏移>.<最大长度>`（STRING），以及 `PE0` / `PA0` / `MK0` 区域别名。
- 按 Windows-1252 处理 CHAR 和 STRING 的扩展字符；导入 STRING 点时保留地址里的最大长度。
- 新增应用内帮助手册，说明西门子经典 S7 TCP 连接、各系列接入前提、地址写法及 viSCADA CSV/XLSX 导入。
- 为其他提供经典 S7 TCP 的设备提供 `generic-s7-tcp` 档案，连接时填写现场 Remote TSAP。

## 使用范围

本版提供经典 S7 TCP（ISO-on-TCP）通信。型号档案给出连接参数起点，具体 CPU、固件和通信模块仍需现场验证。PPI、MPI、PROFIBUS、OPC UA 和 S5 专用协议不在本版范围内；Telegraf 的 `DT` 以及计数器、定时器区域尚未解析。S7-1200/1500 绝对地址读取需核对 CPU 访问权限、PUT/GET 和 DB 标准访问设置。

下载 Windows x64 ZIP，解压后运行 `S7AIStudio.exe`。程序内“帮助”页提供连接与点表格式示例。
