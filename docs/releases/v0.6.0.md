# S7 AI Studio 0.6.0

Windows x64 GUI 正式版。

## 更新

- 界面、帮助与安装包说明统一为正式版。
- 新增软件内“更新”页：检查 Gitee / GitHub 正式版，显示版本、来源与更新说明。
- 确认后下载安装包，支持下载取消、重试、镜像与断点续传；SHA-256 校验通过后才安装。
- 安装前须断开 PLC 并停止本机演示。安装成功后保存通信记录，退出并重启软件。
- 更新源与文档切换到新 Gitee 仓库地址；页面使用通用的源码和下载标签。
- 启动清理只删除软件包自身的旧文件，保留目录中其他备份。
- 保留点表逐点验证、实时进度、单点拒绝后继续读取及已有经典 S7 TCP 功能。

## 使用

首次升级到 0.6.0 时下载 Windows x64 ZIP，解压运行 `S7AIStudio.exe`，无需安装 Go 或 MinGW。之后可从“更新”页检查和安装新版本。源码运行或程序被改名时使用“手动下载”；安装目录需要写入权限。
