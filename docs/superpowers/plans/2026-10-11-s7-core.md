# S7 核心、CLI 与模拟器 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成已确认设计的阶段 A：建立完整 Go 项目，用纯 Go 的经典 S7 TCP 客户端和测试模拟器完成可运行的连接、绝对地址读写、报文记录及 CLI 演示。

**Architecture:** 统一设备、地址和通信事件模型作为模块边界；经典 S7 驱动独立处理协议会话，模拟器和 CLI 使用相同公共模型。现有记录模块改接统一事件并保留旧 Modbus 历史数据，避免重新引入 Modbus 协议实现。

**Tech Stack:** Go 1.26.0 起；S7 TCP 驱动使用标准库；复用参考项目已锁定的 Fyne v2.8.1、modernc.org/sqlite v1.60.1、go-sqlite3 v1.14.52、go.bug.st/serial v1.6.4、x/sys v0.48.0 和 x/text v0.22.0，不在此阶段升级参考项目依赖。

**Spec:** [已确认的全系列设计](../specs/2026-10-11-siemens-plc-design.md)，本计划覆盖第 9 节阶段 A。其他阶段分别制定计划；阶段 A 完成不代表桌面版、Web、PPI、OPC UA、S5 或全系列实机兼容已经完成。

## Global Constraints

- 首版默认内置驱动，不引入动态插件加载或驱动脚本框架。
- S7 驱动和 CLI / 模拟器必须在 `CGO_ENABLED=0` 下构建；桌面原生打包不属于本计划。
- 同一会话默认只允许一个未完成请求；读取可有限重试，写入发送后结果不明时不得自动重发。
- 设备身份未知时保持未知，不根据端口或配置档案推断真实 CPU。
- 能力、地址、字符串长度和整数精度均须显式验证；批量读取按点保留失败结果。
- 不自动更改 PLC 权限、DB 属性、RUN/STOP 或安全相关配置；CLI 默认只读。
- 旧历史文件以原协议展示；只读打开不能迁移或改写用户提供的文件。
- 不发布资产或宣称全系列已验证；当前无 Git 仓库，实施开始时在本目录建立本地仓库，保留所有已有文件，不自动配置或推送远程。

## Review Focus

- 用户输入极大偏移、位索引 8 或负长度：必须在发包前拒绝，不能发生整数溢出；任务 1、4 覆盖。
- TCP 半包、粘包、异常长度和对端一直不发送：帧读取必须有大小上限并受 context / deadline 控制；任务 3 覆盖。
- 取消排队请求、关闭正在等待的连接：不得泄漏 goroutine 或把旧结果应用到新连接；任务 4、5 覆盖。
- 写请求已发送但回应丢失、批量读单项失败：不得自动再次写入，读结果逐项保留质量；任务 4、5 覆盖。
- 带空格/中文路径的数据库、未知历史协议和 64 位整数：文件路径、协议标签和数值应原样保留；任务 1、6、7 覆盖。

## Task 1：建立可测试项目与统一模型

**Files:** 创建 `go.mod`、`go.sum`、`internal/device/{address,value,device,event}.go` 及各自 `_test.go`。

**Interfaces:**

- `ParseAddress(text string, kind DataType, count int) (Address, error)`；Address 含 Area、DBNumber、ByteOffset、BitOffset、Type、Count、Symbol，绝对地址和符号形式互斥。
- `EncodeValue(addr Address, value Value) ([]byte, error)`、`DecodeValue(addr Address, raw []byte) (Value, error)`；Value 包含 Type、Integer string、Boolean bool、Real float64、Text string、Raw []byte，只有对应类型的值字段生效。精确整数使用十进制字符串。
- `Driver`：`Capabilities() Capabilities`、`Read(context.Context, []Address) ([]ReadResult, error)`、`Write(context.Context, Address, Value) (WriteResult, error)`、`Close() error`。
- `ReadResult` 含 Address、Value、Quality、Time、Error，Quality 字符串为 `GOOD` / `BAD` / `UNKNOWN`；`WriteResult` 含 State 和 Error，State 为 `CONFIRMED` / `REJECTED` / `UNKNOWN`。结果与事件的 Error 是可序列化字符串，驱动返回的整体错误仍为 Go error。
- `Event` 含 Time、RequestID、ConnectionID、Protocol、Family、Dir、Operation、Targets、Results、Status、RTT、Raw、Error、可选 Legacy；Results 类型为 `[]EventResult`，EventResult 含互斥的 `Read *ReadResult` 和 `Write *WriteResult`，JSON 元数据保留结果类别；`Observer` 为 `OnEvent(Event)`。Event 不保存 API Key、密码或私钥。
- `LegacyFields` 以 int64 保留 Slave、TxID、Function、Address、Count；仅用于历史解码及测试数据，不提供 Modbus 通信功能。
