# Windows GUI 预览版设计

日期：2026-10-11。状态：用户回复“继续”，书面设计已确认。

## 目标

为现有 S7 核心交付可双击启动的 Windows x64 桌面程序 `S7AIStudio.exe`，无需安装 Go。用途沿用已确认的总体设计：现场连接、点位读取、受控写入、报文诊断与记录。本次先交付经典 S7 TCP 的单工作区 GUI 预览版。

成功标准：用户能启动本机演示，看到 DB1.DBD0 的 DINT 42；显式允许写入 123 后看到确认及读回结果；切换到明确指定的 PLC 地址时使用相同的核心驱动。界面必须正确区分连接失败、单项读取失败和执行结果未知。

## 技术方案

沿用已确认的 Fyne 原生桌面方案及现有 `platform` 字体、图标、日志和窗口尺寸支持，复用 `internal/device`、`profile`、`s7`、`simulator`、`recorder`。新增薄的会话控制器和 Fyne 界面，不通过调用 CLI 子进程执行 PLC 操作。

相比 Windows 专用 UI，这条路线复用现有依赖和跨平台布局；相比本地 Web 包装，它无需新增服务、浏览器壳和 HTTP 接口。本次交付与运行验证限定 Windows x64。

## 窗口与操作

窗口以中文呈现，包含连接栏、点位与结果表、写入操作区，以及报文/日志页签。版本和“预览版”标识始终可见。

- 连接栏：系列、明确的 host:port、连接/断开和状态。高级配置包含 rack、slot、local/remote TSAP、超时及显式 V/VM 映射；按现有档案规则校验，不以系列选择宣称实机认证。
- 点位：输入一个或多个逗号分隔的地址，选择类型和数量，支持单次读取与可停止的轮询。各项分别显示地址、类型、精确值、质量、时间和错误；false、浮点零及 64 位整数不得丢失。
- 写入：默认禁用；用户勾选允许写入并确认目标、类型和值后才执行。保留 CONFIRMED、REJECTED、UNKNOWN 及各段状态。CONFIRMED 后执行一次独立读回，分别显示一致、不一致或无法确认；不会自动重发写入。
- 模拟器：内置本机演示按钮，监听仅限 127.0.0.1，使用实际绑定的空闲端口，填入连接目标并读取默认点位。明确标注为合成协议对端。停止或退出时释放监听端口。
- 记录：默认保存到 `%AppData%\S7AIStudio\records`，采用现有按天/50 MB 轮转的 SQLite 归档。记录失败在界面可见，不能报告为成功记录。
- 报文与日志：展示真实 TX/RX 字节、操作、引用、状态与错误；只保留有限条近期显示项，完整归档交给 Recorder。记录路径和最近一次保存错误可见。

本次不实现多工作区、CSV/XLSX 点表导入、历史文件浏览、AI 助手、Web、其他协议驱动或自动更新；这些模块按总体设计另行推进。界面只提供本版已经实现的操作。

## 控制器与生命周期

新增 `internal/service` 作为 UI 与现有驱动之间的边界，负责配置校验、连接、读取、轮询、写入和读回。协议编码及地址/值解释继续由现有核心负责。

同一会话的操作串行执行。耗时工作在后台进行；Fyne 控件仅由 UI 线程更新。连接与轮询带取消和会话代次，断开或切换连接后丢弃旧结果，避免旧连接状态覆盖新连接。

传输故障导致会话失效时停止轮询并显示需重新连接；不自动重试写入。读取的已完成项保留原质量，不因后来项失败丢失。

退出顺序为取消后台工作、关闭驱动与模拟器、排空记录队列并关闭数据库；不遗留监听端口或未结束的会话。正常退出过程中的保存错误写入应用日志。

## 文件边界

| 位置 | 职责 |
| --- | --- |
| `cmd/s7-ai` | GUI 入口、版本、平台设置和退出处理 |
| `internal/service` | 会话控制器、读写/轮询/读回、可测试的状态和事件 |
| `internal/ui` | 中文窗口、表单、结果、状态与报文日志 |
| `build/windows.ps1` | 使用本机 MinGW 构建静态运行库的 GUI，写入图标/版本/高 DPI 清单，打包与生成 SHA-256 |
| `platform/windows` 或打包专用说明 | 与实际 GUI 功能一致的运行说明 |
| `README.md`、`docs/development.md` | GUI 构建入口与本版能力说明 |

现有 CLI 和模拟器入口继续保留。已有 alpha.1 发行版资产不覆盖；本次 GUI 包使用 `0.1.0-alpha.2` 预览标识，Windows 数字文件版本为 `0.1.0.0`。本次先交付本地构建产物，远端发布另按版本和验证结果执行。

## 验证与交付

先以行为测试验证配置错误不拨号、默认只读、读回一致/不一致、UNKNOWN 不重试、部分结果保留、断开后的旧结果抑制和退出取消；然后连接现有合成模拟器做集成测试。

使用 Fyne 软件渲染测试默认控件状态与中文布局；完成原生 Windows 构建、PE 架构/运行库依赖、图标/版本/高 DPI 清单核对，以及启动和本机演示验证。运行全仓静态检查与测试；使用已找到的 MinGW 执行适用的 race 检测。

交付绿色 ZIP，包含 `S7AIStudio.exe`、运行说明和版本信息，附 SHA-256、测试结果及截图证据。只对实际完成的验证作出声明；合成模拟器不能替代真实 PLC 验证。
